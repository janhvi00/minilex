MiniLex

Describe each token with a regular expression, paste some source text, and read off the tokens. It builds an NFA from your rules and takes the longest match at every position, the same algorithm as the C++ original.

Rules

one per line: regex TOKEN_NAME
Rule syntax
  • Literals, . (any character but newline), [abc], [a-z], [^abc], ( ), |, *, +, ?
  • Escapes: \n \t \r \\, or \ before any operator to match it literally
  • The last word on the line is the token name. SKIP discards the match (whitespace, comments)
  • The longest match wins. On a tie the earlier rule wins, so list keywords before identifiers
  • To match a space, write [ ]. Lines starting with # are comments

Source text

    Console output matches what ./minilex prints for the same rules and input. Columns count bytes, as in the C++ version.
